# RunAgain — Verified Revival of Abandoned Python Research Code
Track: Coding and Agentic Engineering. Status: scaffold (untested).
Loop: sandbox run -> Tavily research -> Nemotron (Nebius Token Factory) picks one bounded fix -> rerun -> exit 0 = revived.
Setup: copy `.env.example` to `.env`, fill keys, `pip install -r requirements.txt`, then
`python -m runagain.loop <repo_url> <commit> "<verification command>"`.
See SUBMISSION.md and benchmark/repos.json.
